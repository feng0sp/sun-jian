# 0.13.1 · 一晚借宿，一早再会

## 本轮结果

保留现有三次拆解、一次合回、三处必经取料和五处自选练习，补齐休息、出发、推车返村、坐下告别的衔接。

- 收好样木后，周伯只招呼一句吃饭。选择休息后出现晚饭后收好的碗筷；点击进入第二天，不增加吃饭任务或等待。
- 前一晚查看过雨棚的玩家主动提起长凳；没有查看过的玩家从周伯核对尺寸的速记引出帮忙。尺寸速记与旧库中的装配草图区分清楚，两条路线都说明替换料已经试配。
- 出发对白明确交代背上晾干的背包。提交出发后才移除室内绘制层；坐下告别时，背包放在长凳旁。
- 取回物料用三个短画面交代装稳小车、沿石路推回、停在雨棚，随后回屋叫周伯。物料与草图仍可任意顺序取得。
- 检查长凳后，主角邀请周伯坐下，再切换到坐姿；两句回应之后写下手记，默认按钮为“再坐一会儿”。回到雨棚全景时，周伯仍坐在凳子上。
- “昨晚没坐成”等回顾只在确有夜间观察时出现；旧存档无法证明的经历使用中性文案。

## 交互与内部接口

`CampaignInterludes` 提供三段数据驱动片段（`overnight`、`homeward`、`farewell`）和阶段校验。活动片段仅覆盖场景呈现，不修改正式解谜历史；最后一步或略过时一次性提交章节变化。

片段支持 Enter、Tab、Esc 暂停、略过整段、图片失败重试；图片载入失败时也可略过。无 WebGL 仍可阅读。按减少动态效果直接切图，音效沿用开关且默认关闭。对话期间背景热点停止响应，画面不使用模糊遮罩。

继续使用 `sun-jian-campaign-v1` 与数据版本 2，剧情修订号为 5。新增 `nightBenchSeen`、`interlude`、`interludesDone`。刷新恢复已提交的片段步数；旧版已过清晨、返村、结局的存档不会补播前置片段。迁移前原始内容备份在 `sun-jian-campaign-v1-backup-before-narrative5`。开场回顾与旧练习存档隔离。

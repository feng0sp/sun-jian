# 0.13.11 · 三处地点的轻配乐

日期：2026-11-06。本轮将原先偏长、偏低的持续音改为三套独立短句，保留游戏原有本地 Web Audio 音景接口。旋律、节奏及程序编配均为项目原创，没有新增外部音源、下载服务或运行时网络依赖。

## 三套主题

| 配置 | 主题与动机 | 音域 | 结构与尾音 |
|---|---|---|---|
| `journey` | 旅途与雨景：A—D—E 上行后，以 F♯—A—D 应答；疏落的清亮拨弦给雨声留位置 | D4—F♯5 | 每段 9.6 秒、6 个落点，8 段共 76.8 秒；单音 0.46—0.82 秒 |
| `home` | 小屋日常：D—F♯—A—D 与 B—A—F♯—E 构成问答，随后经过 Bm、G、A 的短句变化；轻钢琴感与短拨弦 | G3—F♯5 | 每段 8 秒、8 个落点，8 段共 64 秒；单音 0.54—0.92 秒，G3/A3 只作短暂落点 |
| `workshop` | 白天工坊：D—E—A 的跳进和 F♯—E—D 的短回答，速度更明快，木质高泛音与停顿交替 | E4—A5 | 每段 6.4 秒、10 个落点，8 段共 51.2 秒；单音 0.24—0.43 秒，每段末留约一秒空处 |

三套主题均使用 D 大调相容音，现有周伯、小许、林岚与主角的提示音继续协调。旅途／小屋的二次泛音与工坊较短的三次泛音形成音色区别，三个场景不是把同一旋律简单升调。低音连续铺底已去除；小屋保留少量短中低音，避免整段只剩高音。

## 接入与行为

只修改 `dist/journey-atmosphere.js` 的 `scores` 和音乐音符的 `levelScale`，原 `configure`、静音、雨声／敲门、对白音效、后台暂停和跨场淡出接口均保留。`home` 的短音响度补偿为 1.25、`workshop` 为 1.2，使增加留白后仍能辨认旋律；没有提高主音量或改变雨声强度。对白仍按原混音压低配乐，翻页不重启乐句。

这些曲目包含有意的停顿。测试应观察跨完整短句的实际信号，不能以任意 100 毫秒内必须有发声节点作为正确性条件。

## 试听与数值检查

文件均在 `output/polish-01311/music/`：

- `旅途与雨景.wav`、`小屋日常.wav`、`白天工坊.wav`：各 24 秒，48 kHz 单声道 PCM；使用生产 `playNote` 与当前旋律数据在浏览器 `OfflineAudioContext` 中渲染，采用默认 0.65 主音量和对应未压低场景增益。
- `render-preview.cjs`、`analyze.py`：可复现渲染与分析；`verification.json` 记录原版和新版的 24 秒波形指标。
- `three-themes-runtime.webm`、`runtime-verification.json`：真实 Web Audio 输出及切换、静音、后台与对白压低的状态检查。

# 《榫间》完整初版 0.14.0

## 本轮变化

在既有0.13.11人物、图片、纠错与告别修改上，接通备赛到第三名的后半段。最终作品三选一：换鞋小凳、床边小几、桌上书架。使用同一可拆修原则，各有实际几何、用途与展位绘制状态，不只是更换菜单名称或颜色。三者均获得虚构省级新人组第三名。

主线经过遇雨借宿、主动学习、三必经取料、修凳告别、返校工坊与报名、维修样机、参赛制作、正式装配、局部拆修与复装、过程说明、结果及继续学习。未做五处自选也可完成。

## 结构与保存

- 支撑框架固定，主板和两枚侧向木销为三个操作构件；先主板、后两销，销可交换先后。三模型先验证几何后出场景画面。
- `entry-shoe-stool`、`entry-bedside-table`、`entry-desk-shelf` 分别验证合法记录。四条备赛/现场任务各自保存，不能互相代替。旧长凳成绩不授予新奖项。
- 主键不变、数据版2、剧情修订10、continuation修订4。旧原文在首次写入前保存在 `sun-jian-campaign-v1-backup-before-full14`，旧工坊完成档进入作品准备。此前0.13.11的修复也保留其迁移备份。
- 出发前可明确改选，清除的仅为本次作品历史与检查，不改已有第一幕/样机。出发后锁定选择。比赛中途、刷新、退出和重练隔离。

## 验证与边界

规则测试验证无初始穿插、所有可达拆解状态有后续、两销换序、逆序复装、非法历史/错作品不能授奖。浏览器实际指针覆盖三作品、短拉、撤销、最高级提示、三段比赛退出刷新、获奖后独立重练和三尺寸。

完整新游客测试使用同一浏览器从第一幕继续到第三名，不在中途用夹具跳到后半段。另测旧档迁移、无WebGL方向操作、图片失败和离线。每项实际结果以 output/fullgame-014 下的独立JSON为准；不把计划当结果。

对白通读按人物在场、知情、当前作品及操作结果核对。图片核对轮廓、件数、散件/合好、人物身份、光源与阴影。音乐沿用本地三主题，赛后回温暖日常主题，首次关闭，录制真实运行音轨供试听；自动信号验证不等于人工听感评估。

画面为完成/散件等里程碑状态，不为每枚销的中间位置生成独立插画；中途返回会明确显示已装/已取数量，三维特写保留精确合法局面。新增15张场景共5.15MB，三种作品×五个状态，已验证45组画面状态与桌面尺寸。

首次真实玩家反馈尚待采集。初版不包含移动端行走、自由旋转装配、真实加工模拟、账号或云存档。完整流程是否足够有趣、时长是否适宜仍需要真人试玩。

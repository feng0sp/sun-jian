# 《榫间》0.15.0 博物馆展签与素材来源

工坊实作结束后，林岚和主角在一份旧椅维修记录前停下。玩家从第一视角点八件展品或展台上的名字，可以比较整件、接点和分解图。0.15.5 起八件均可打开教学复原件拆解和复装。任意时间都可以离馆选参赛作品，后续可从旅行笔记重访。

梁头榫可沿梁长退出，斗栱可自上而下分层拆开，粽角榫的两根边框各走自己的卯口，椅架只拆横枨接点。走马销教具把宽口延长至板边，并加教学限位木块，便于观察取下限位后滑板如何沿槽退出。

展厅和教学桌为本作 AI 辅助绘制的原创场景。二十四张观察图用本作的木构网格渲染。图例用于观察接合关系，展厅陈列为虚构，游戏中的复原件采用简化示教几何。

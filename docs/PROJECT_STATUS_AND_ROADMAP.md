## 验证证据的用途

本轮输出位于 `output/polish-0142/`；离线包位于 `output/campaign-0142/`。

- `global/verification.json`：长凳状态、三个桌面尺寸、音乐暂停／后台、存档导入撤回、比赛角色提示音。
- `save-transfer/verification.json`：三种尺寸的存档预览、键盘取消、存储失败、双提交防护、精确备份。
- `visual-states/verification.json`：93 个场景状态／尺寸组合、图片解码与失败重试；contact-*.jpg 供画面通读。
- `awards/verification.json`：三种作品、人物神态、回看、刷新、旧档和正式证明隔离。
- `music/recordings.json` 与 `waveform-verification.json`：五段真实程序音景输出与波形边界；不是人工听感结论。
- `audio-endurance/` 与 `scene-endurance-final/`：有真实开始／结束时间的长时运行记录；只有 verification.json 的 passed 才代表完成。
- `extended-endurance/`：最新两小时场景、取消拖动、暂停、独立音量与内存记录，仍以最终JSON为准。
- `paced-full/`：有阅读停留的自动全流程；自动测试按规则选操作，不能充当首次玩家。
- `release.json`：源码、保存云端版本、部署、离线包及在线访问限制分别记账。

不以自动通关证明对白自然、手感优秀或体验必然达到 45—60 分钟。三名首次玩家的记录仍待实际邀请，使用 [试玩模板](FIRST_PLAYTEST_TEMPLATE.md)。

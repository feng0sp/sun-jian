# 0.12.12 · 小屋里的温度

本轮围绕已有家具与电灯添加动态，没有把火焰叠在电灯上，也没有改动人物、背景画或榫卯规则。

- 雨夜小屋的搪瓷杯口缓慢升起五缕交错热气，升高后渐隐。
- 吊灯附近与桌面投光区域增加约十秒一轮的微弱暖光变化，无闪烁或矩形遮罩。
- 动态使用同一画面坐标和二维层，适配五种任务状态的夜间小屋背景；人物面部与操作木件保持清楚。
- 室内配乐使用独立的原创柔和和声段落，节奏比户外慢 20%，高频更弱。进出房间平滑调整音色，保留当前乐句；不在切换场景时重新播放开头。
- 继续沿用“声音”开关，首次静音。减少动态效果、页面后台、菜单和三维操作特写暂停屋内动态。

验证：`tests/indoor-atmosphere.test.cjs` 在 1280×720、1440×900、1920×1080 检查杯口与灯光区域确实变化、人物面部无叠加、默认静音、配乐场景选择、进出拆装和系统减少动态效果。`tests/rain-atmosphere.test.cjs` 回归既有雨夜、热点、切场景与音频生命周期。

原存档键与进度均不变，无外部音乐资源或运行时网络依赖。截图与发布记录位于 `output/experience-01212/`。这是开发者验证，不代替玩家对动态与音乐的主观体验评价。

# 0.13.5 · 完整旅程的操作承接

本版沿用二维点击探索、独立三维拆装与原存档。主线从雨中下山开始，到修好长凳、周伯检查、坐下等同伴结束。无需开发菜单选关，也不要求清完自选练习。

## 本轮更新

- 木料库八种结构完成后都提供结果反馈、返回按钮和继续观察。必经结构说明眼前的变化；自选结构说明观察所得，不再套用旧三维洞穴里的“解锁下一道门”叙述。
- 穿销门闩、双扣挡框、草图木匣分别使用对应物件名称。完成后的下一事项取决于实际取料进度，两种取料顺序都自然衔接。
- 返回按钮仍回到进入前的画面。继续观察或 Esc 不直接推进；撤销后重新完成可以再提示。重练不覆盖主线。
- 小屋、石路和旧库的已有路线中，轻微强调通往当前事项的方向。方向来自已经开放的路线，不自动移动、不越过敲门与取料条件、不告诉玩家正确拆法。
- 取齐东西后的返村入口得到同样强调，主线不被五种自选结构阻挡。

## 连贯流程

| 段落 | 玩家行动 | 接下来的结果 |
|---|---|---|
| 雨中来客 | 下山进村，可先看雨棚，敲门求助、放包、主动询问借宿 | 同伴住处得到交代，开放小屋观察 |
| 灯下识木 | 从椅子或周伯处主动提出学习；三次拆解、一次合回 | 收好样木，吃饭休息到清晨 |
| 清晨取料 | 接受取料委托，背好包，沿石路到旧库 | 拆开穿销门闩进入储料区 |
| 静洞寻木 | 双扣挡框取料、木匣取图，先后不限；其余五种随意练习 | 木料与草图齐备，可以装车返村 |
| 把木合好 | 回屋喊周伯；预装横梁后亲手装座板及两枚销 | 周伯检查接缝，开放坐下 |
| 雨后再会 | 邀周伯坐下，给同伴发消息，写下最后一页 | 完成旅程，可继续看景、看手记或重练 |

## 检查方式与证据

`tests/campaign-2d.test.cjs` 从空白浏览器存档、新旅程按钮开始；主线不注入完成记录。覆盖直奔小屋／先看雨棚、椅子邀请／直接向周伯学习、真实鼠标拖入长凳三件、仅完成三处必经即到结局。额外分支单独使用已学习夹具，验证八种结构均可练习、料架与木匣换序完成、刷新保留记录。

`tests/journey-0135.test.cjs` 实际拖出库门小销，检查完成后观察、撤销、重新完成、双击返回、胜利局面刷新恢复、自选重练隔离，以及三个桌面尺寸的完成弹窗。

回归包括：合法历史与旧存档迁移、两种木销顺序、提前插销恢复、图片超时及重试、后台模式保存隔离、续玩卡片、快速打开退出、无 WebGL 的方向操作。

自动测试中的解法由规则层给出，因此只验证流程、几何操作和状态正确性，不代表首次玩家能自然找到解法，也不用于估计游戏时长。

## 对白与画面通读

- 未看雨棚时，清晨由眼前草图引出修凳；看过的玩家才提及昨晚的长凳。
- 旧库内只有物件观察和手记反馈，没有周伯隔空讲话。
- 库门反馈不宣称已经取到木料；料架、木匣只说明自己对应的结果。
- 自选六件锁不再宣称打开旅程出口。即使不拆它，玩家也能完成取料修凳。
- 完成反馈为短段文字；后续位置提示单独一行，三种桌面尺寸不遮挡返回按钮。

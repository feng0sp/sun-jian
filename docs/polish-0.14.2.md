# 0.14.2 · 场景、操作与音景的全局修整

2026-11-07。沿用完整七章、男性大学生主角、女性小许、三选一作品和第三名结局。本轮没有增加必经关卡或清空进度。主存档数据版2、剧情修订11、continuation修订4保持。

## 场景与操作

- 长凳接点近景原来固定使用另一种装配状态，现改为同一个 `benchPainting()` 结果。图片、绘制层、雨层和热点一同放大。正式装配有两梁预装、座板和两销的状态变化。
- 长凳相机原先按包围球取景，对细长模型留出太多空白。现在按相机投影中的实际轮廓计算距离，同时包含拿起的座板与目标。试过更正面的角度后，发现前后轴与上下轴靠近；最终保留原来的易辨轴观察方向。
- 被拿起的装配件使用实体表面和正常遮挡；半透明目标位置保留，避免实体木件像一团透视线框。模型几何、连续碰撞、真实出口和归位吸附没有改写。
- 真实复现并修复：装好座板后撤销，散件会超出原取景；现在撤销同步按原角度重新取景，三尺寸下无需重选即可再次拖入。
- 三种窗边坐姿视角移出工作台，解决另一机位上的木料与持久清单不符。夜间周伯、白天周伯、白天空椅构图一致；窗雨、杯口热气按新图校准。退出可直接起身回屋或去工作台。
- 热点名称只在物件附近显示，删除重复的底部名字；透明交互区域仍有键盘焦点。工坊任务卡减轻背景遮罩，菜单与对白保留各自输入锁定。
- 章节统一为七章；重练完成不再要求重新决定报名；主菜单区分继续备赛、继续现场、赛后交谈与回到赛后。库门开场把旧“小销”文案改成实际模型上的宽木钥。

新图由内置 ImageGen 以现有画面为编辑参考制作，Pillow仅作编码和缩放。完整提示词和限制见 [坐姿素材记录](chair-rest-assets-0.14.2.md)。可编辑生成PNG保存在 `output/polish-0142/chair-assets/`。新图是插画重构图，不是房屋的几何精确镜头；不同昼夜图的杯纹、椅子细节存在轻微笔触差异，不把它们描述为逐像素一致。

## 音乐与对白音效

保留原旅途、小屋、工坊主题，新增两套原创程序编配，无外部运行时音源：

| 地点 | 配置与节奏 |
|---|---|
| 雨路、村口、门前 | journey，稀疏拨弦，与两种CC0实录雨声配合 |
| 小屋、返校住处、赛后 | home，轻钢琴感短句，保留短中低音落点，不加持续低频 |
| 旧木料库 | store，12.8秒一段、5个落点、8段；较长留白与轻木质泛音 |
| 白天开放工坊 | workshop，6.4秒一段、10个短落点 |
| 正式交流赛 | gathering，6.8秒一段、7个落点、8段；比工坊放宽节奏 |

暂停、普通记录面板或后台中断保存各主题的下一个音符和余下等待时间，回到同主题接着播放；新旅程和确认导入重置乐句书签。对白翻页与音量变化不重启短句。已获奖后回顾第一幕按当前地点配乐，不再被获奖标记强行覆盖。

评审、工作人员有各自简短提示音；旁白、手记、装配记录仍静音。首次静音、单独对白开关、室内雨声衰减、切后台停止及快速切曲尾音回收保持。

总音量之外提供背景音乐、雨声独立滑杆，旧档两项默认1，不改变原有混音；键盘可调，刷新保留。雨声试听遵循雨声音量。

实际生产音频各录32秒，文件 `output/polish-0142/music/{journey,home,store,workshop,gathering}.mp3`；原WebM、录音状态和波形指标同时保留。五段峰值约0.0187—0.0434，没有削波；这些数值验证信号与边界，不证明悦耳。未进行真人听感测试。

## 本地存档恢复

设置内增加“从文件恢复旅程”：

1. 只接受游戏“下载旅程存档”的JSON封装，最大4 MB，内测记录不可导入。
2. 通过原来的合法历史恢复重建进度，缺失比赛证明不能凭奖项标记直接获奖。
3. 预览位置、学习与取料进度，确认前不修改当前旅程。
4. 保存原文到 `sun-jian-campaign-v1-backup-before-import` 后提交；可“撤回上次导入”。
5. 声音设置保留当前选择，原自由练习与独立试玩不受影响。存储失败保持当前状态，旧确认按钮的重复提交不会替换原备份。

支持在线和离线版之间人工转移；没有账号、上传或云存档。

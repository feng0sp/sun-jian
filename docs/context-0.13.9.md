# 0.13.9 · 人物陪伴、实录雨声与情景木构

日期：2026-11-06。沿用二维场景、独立三维特写和桌面游客版。此轮完善借宿到工坊已有内容；S05 参赛小凳、S06 正式比赛和 S07 第三名仍待制作。

## 本轮内容

- 小许为年轻女性徒步同伴，现场对话在左侧显示半身像，平常、担心、带笑三帧；主角说话时降低强调。消息改为头像和消息气泡。图片失败保留文字。
- 周伯新增放松眉眼的欢迎神情，仍保留原年长面部与朴素衣着。
- 山路用树叶实录雨声，村口／门前用院落实录。设置可选自动切换或固定一段，并可独立试听。首次静音；切场淡入淡出、室内衰减、后台暂停、音乐和木件反馈保留。两段 CC0 来源和处理哈希见 [授权记录](rain-0139-licenses.json)。音频编码进本地脚本，支持离线 file URL，不调用外部音源。
- 敲门触发两下轻敲，主人邀请由剧情节点一次提交；静音仍可完成，连续点按不重复邀请。
- 直榫、半榫、穿销均可反复拆合，完整拆开下次合回，合好下次拆解；半途退出则继续。全景、近景和收纳盒使用同一份合法历史，木件只放一份。穿销包含提前装销的部分状态绘制，不能只按通关布尔值判断摆放。
- 新增椅腿横枨长榫、两件宽料端部 L 形搭接、库门宽钥与长横闩。三个结构均由本地几何生成，实际外形与碰撞共用尺寸。门闩须先取钥，再向左横移；不能直接把旧穿销方块改标题冒充库门。
- 角尺改为拿起、靠齐、检查直角的轻互动，再可打开旁边端部搭接料。椅子上的是同形示教件，修好的邻居旧椅仍保持完整。
- 活动统一为虚构“省级木作交流赛·新人组”：省城现场，溪桥宣传与传习；省内、系统学习未满两年、未从事木作职业。林岚断续学约一年，主角约十周准备。同步折页、报名、手记、蓝本和制作助手。
- 暂停菜单增加完整旅程存档下载，仍只保存在浏览器本地，不上传。

## 状态与兼容

主键仍为 `sun-jian-campaign-v1`，数据版 2、剧情修订 8、新篇修订 2。迁移前原文备份到 `sun-jian-campaign-v1-backup-before-context8`。正式证明 `runs`、独立重练 `replays` 与物件摆放 `roomObjects` 分开；反复把样木合好，不得清掉曾完成的课程。

旧库门仍用 `mouth-latch` 节点：完整旧证明继续有效；已取小销的合法半成品映射为新木钥已取下。不能映射的非法历史仅重置该接点并提示，原文仍有备份，其他章节不动。原版库门独立练习半成品可继续旧模型，新开练习使用新横闩。旧自由练习、小屋试玩、洞穴试玩不迁为本轮主线通关。

## 制作入口与素材

`campaign-objects.js` 管物件位置；`context-puzzles.js` 管三种情景结构；`companion-dialogue.js` 管小许；`square-check.js` 管角尺；`sample-close-art.js`／`sample-wide-art.js` 管绘制状态。`scripts/prepare-sample-art-0139.py` 从既有绘制件与生成原图整理透明图层，保留纹理和接触阴影，不在全景叠微型三维模型。

人物、门闩、工具角与样木素材来源记录：`xiaoxu-0139-art.json`、`context-scenes-0139-art.json`、`sample-painting-0139.json`、`sample-close-art-0139.json`、`sample-wide-art-0139.json`。几何说明见 [情景结构记录](context-models-0139.md)。

# 0.13.0 · 循着灯光进村

## 已实现的开场

新旅程从雨中下山石阶开始。交代原计划是和同伴徒步、穿过溪桥村下山，因傍晚雨势加大改为进村避雨。玩家沿灯光进入村口；同伴去小卖部问住处，主角可先看雨棚缺座板的长凳，或直接去亮灯的小屋。

小屋门口独立成景。先敲门，听到屋内邀请后再点击进屋；老人提醒擦鞋放包，交谈后才得知他姓周。背包放稳后出现对应绘制状态，玩家主动问山路及借宿。消息确认同伴已有住处，随后回到屋内自由观察与主动学习木作。没有新增等待、找路谜题或强制雨棚检查。

雨中山路、门口细雨和屋檐滴水沿用本地动态层，进入小屋衔接窗外雨、热气、暖光及室内配乐。首次仍为静音；减少动态效果使用静态场景与直接切换。

## 状态与兼容

存档仍使用 `sun-jian-campaign-v1`、数据版本 2；剧情修订号为 4。`prologue` 保存山路、村口、获邀、进屋、放包和安顿阶段，邀请和背包状态由有效阶段恢复。未获邀请不能进入屋内；未放包不能跳进工作台特写。敲门、邀请、动作与选择节点可刷新续玩，未播放的动作不算完成。

旧修订号玩家保留所在场景、学习成绩和合法解谜历史，进入时不强制重播山路。旧原始存档首次保存前备份至 `sun-jian-campaign-v1-backup-before-opening4`。旧版停在初次见面的玩家仍有相应的问候和自我介绍，不会突然以已熟识的语气交谈。

菜单“重看开场”使用独立的 `sun-jian-campaign-v1-opening-replay-v1`，URL 带 `openingReplay=1`，刷新可继续回顾。回顾期间不改主旅程存档；安顿后提供返回原旅程，也可中途结束。回顾不授予木作学习成绩。

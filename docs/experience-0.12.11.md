# 0.12.11 · 雨夜动态、配乐与场景衔接

## 画面检查与改动

- 原切换只替换图片并从 0.88 透明度淡入，容易露出底色；新热点还可能先于新画面出现。现在预加载并解码完整图与状态图层，保留旧画面，使用 320 毫秒的交叠淡入。加载和过渡期间隐藏并禁用新热点；减少动态效果时直接切换。
- 村口不再通过移除底部导航行改变画面位置，村口与小屋保持相同画幅和纵向位置。
- 检查雨棚、小屋、村口箭头和旧库的鼠标悬停、按下与键盘焦点。观察区域不填充底色，去掉大区域发光，只保留细轮廓与紧凑名称。
- 场景载入失败仍保留旧画面、进度、重试入口。阻止全局人物图片重试逻辑误处理场景层。

## 轻雨与原创声音

新增 `journey-weather.js`：轻量二维雨线和村口前景水圈。按绘制画面的坐标裁切到户外、雨棚外和小屋窗外，避开人物、工作台、屋顶及家具。没有重新叠加微型三维模型。

白天、隐藏视图、菜单、拆装特写、页面后台和减少动态效果状态停止雨线；支持系统减少动态效果偏好。画面仍完整呈现，雨层不接收鼠标事件。

新增 `journey-atmosphere.js`：原创八段疏落音符组成的舒缓配乐，搭配低音量雨声。全部由本地 Web Audio 合成，不下载或流播第三方音乐。顶部“声音关／声音开”沿用原音效开关，首次默认关闭，并要求用户操作后才启动音频。室内雨声减弱，对话和拆装时配乐压低；菜单、离开旅程与页面后台暂停，切场景不会重启旋律。

音量沿用设置中的总音量。没有增加账号、请求权限、外部服务或新存档键。

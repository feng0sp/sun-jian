# 0.13.8 人物对白、音乐与场景演出

日期 2026-11-06。当前可玩范围为借宿、修凳、报名及工坊维修样机。按 Story Agent 完成这一范围的对白和演出；参赛小凳、正式比赛与第三名仍在后续切片中。发布结果以 output/performance-0138/release.json 为准。

## 对白与节点

| 稳定节点 | 人物、时间及行动 | 本轮调整与恢复 |
|---|---|---|
| opening、villageArrival | 第一晚，主角和小许进村，分头找屋檐与住处 | 从山路使用小许姓名；各人行动与随后消息对应 |
| stay、travelMessage | 借宿、次日取料 | 小许以消息发言；明确告知取料是为修凳，支持会合时的折页对白 |
| heritage、teacherMemory、invite | 周伯夜间在小屋 | 从传习点和修椅经历展开；晃椅的笑意与邀请动手的视线绑定到实际台词 |
| after:learn-* | 四次正式学习已完成，收好样木 | 完成弹窗与早退后的承接各用一句回应，不再重播玩家总结 |
| continuationMeetup、continuationDeparture | 修好的长凳边，周伯与小许在场 | 由修凳消息引出折页；继续练习的意愿由主角主动提出 |
| continuationPurpose | 第四周，与小许通信 | 换鞋、搬动、维修三个选项各有独立问答；不让最后一句跳回另一个话题 |
| continuationPeer | 林岚在工坊，与玩家一起看样机 | 先问手从哪儿伸，交还操作；凝视向桌面 |
| continuationServiceReflection | 侧置合回、拆修均有合法完成历史 | 玩家确认销已取出，林岚再讲自己的失误，放松带笑；邀请以后互试作品 |

手工通读检查了人物是否在场、物件位置和已知信息；修正了小许原先被笼统称为同伴，以及取料消息没写修凳却在会合时被引用的衔接。已有雨棚观察记录决定“昨晚没坐成”是否出现。通读是作者检查；尚无本版首次玩家访谈。

## 表情与光影

新增 campaign-expression.js，以画面的实际内接尺寸安放四张透明局部绘制。周伯限于 room-table-night-0 至 4，林岚限于工坊有人的原画。回看上一句、关闭对白、退出特写和刷新都会从当前台词恢复。图片失败回到原画，不阻挡选项。

两位人物各有两张内置 ImageGen 原创编辑，代码中的台词第三项为可选 cue。源图、提示词、套准与哈希见 lin-expressions-0138.json 和 zhou-expressions-0138.json。四张正式资源位于 dist/assets/campaign-2d/expressions/，共约 60 KB。

工坊借用原画窗边墙上的光斑作局部低幅度移动，维持家具和脸部轮廓。表情、原画和光影共用同一幅画的坐标。菜单、后台与拆装时停止叶影，减少动态设置和系统偏好均关闭循环与淡入。原雨夜的窗雨、热气、暖光继续按现有坐标绘制。

## 音乐与输入

journey-atmosphere.js 继续在本地生成原创音符与雨声，configure 增加 profile 字段，使用 journey、home、workshop。旧 home 参数仍可调用；quiet 用于压低交谈和拆装时的配乐。相同场景翻句保持乐句；切场淡出旧音，后台和静音清除待发音符后暂停。

雨声进屋后约为室外的 37%，配乐 quiet 目标为正常的 38%。工坊乐句有整段休止。首次静音、可信指针解锁、快速切场残响和隐藏时的零采样均经实际浏览器输出验证。测试注入的录音器同时镜像真实配乐及木件音效两个 AudioContext，不进入游戏发布包。

修正了工坊流程面板按 Esc 无法打开暂停菜单的问题。也修正从主菜单进入设置后返回位置不对的问题；可以设置声音再继续当前阶段。

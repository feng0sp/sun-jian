# 0.13.6：带走的不只一页

日期：2026-11-05。范围：S01—S03 首批可玩流程，至工坊练习、主动复盘与报名准备。S04—S07 的作品设计、比赛与第三名尚未实现。公开发布结果以 `output/continuation-0136/release.json` 为准。

## 实际行为

- 原修凳结局保留，并标为第一幕完成；完成页和主菜单都增加“继续后面的故事”。旧通关玩家可直接进入，不重做原关卡。
- 小许如约到雨棚会合，带来虚构木作交流赛折页。玩家可当场看或收好；活动规则可反复查看，不当场强制报名。
- 主角向周伯询问继续学习的方式，和同伴离村。回家后的第一个周末预约开放工坊，阅读基本说明后接触待检样机。
- 穿销合回练习使用独立历史。初始小销已装，真实碰撞会阻挡大件；可以撤销回收，也可以重置成散件。正确合回后给出中性完成反馈，不让不在场的周伯隔空表扬。
- 复盘标记“取销—退出大件”的通路，再明确选择报名；可暂不提交并重读规则。报名只是本地游戏事件，不向外提交资料。
- 本次内容结束于准备计划，提供回雨棚、手记与规则入口，没有点不开的下一章。

## 实现与存档

新增 `dist/campaign-continuation.js` 管理新篇状态、合法练习恢复与对白。`campaign.js` 继续负责界面和规则引擎调用。

保留存档键 `sun-jian-campaign-v1` 与数据版本 2，增加向后兼容的 `continuation` 命名空间；剧情修订升至 6。旧原始存档在首次写入前保留到 `sun-jian-campaign-v1-backup-before-continuation6`。原 phase、runs、replays 不被新练习顶替。

新篇 stage 按真实前置和合法练习历史恢复，不能仅凭 stage 或 entryAccepted 标记跳过练习。没有完整旧主线证明时不开放新篇。旧 complete 表示第一幕结束，不表示比赛获奖。当前没有授奖字段或假比赛成绩。

新背景、对话与特写共享工坊图；回家过渡使用安静的色面与文字，不冒充另一幅已完成场景。新篇可回到雨棚回顾，再从菜单续玩。比赛前的其他章节未制作。

# 0.13.4 · 接着上次继续

本轮围绕中断后续玩、对白阅读和场景操作做小幅升级。沿用二维动漫场景、三维拆装、游客访问和原来的完整故事。

## 玩家能看到的变化

- 手记前面显示还没试完的练习，注明“已取下／已装好几件”。小屋样件、木料库样件和长凳都能从保存的局面继续。
- 普通重练菜单同步显示“继续拆解／继续合回”。已经完成的练习再次进入才重新开始，主线完成记录不变。
- 长凳进度只计算座板和两枚木销，不把周伯预装的横梁算进去。
- 主菜单显示上次所在场景和当前目标；拆装恢复后说明已经做到哪一步。
- 同一段对白可以回看上一句。选择、任务和物件动作不会因此重复执行；单句的重复回应保持简洁。
- 长按 Enter 或空格不会连跳台词或替玩家选择；反馈文本框仍可正常输入。
- 场景入口区分向前与返回方向；“起身”“取料备忘”随场景状态立即更新。
- 修好的长凳使用已经完成维修的回应；周伯去雨棚后，屋内旧椅的观察不再出现隔空回答。

## 修正的切换问题

快速打开再退出特写时，原来的下一帧回调仍会重新启用隐藏三维视图。现在回调检查当前任务与视图；退出、换件或打开覆盖窗口后，不再恢复过期视图。

对白切换原来延迟设置焦点，可能覆盖玩家刚选中的另一个选项。对白现在在内容更新后直接设置焦点，其他面板也保留已经落在面板中的主动焦点。

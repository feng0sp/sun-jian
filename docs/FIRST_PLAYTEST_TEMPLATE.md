# 《榫间》首次玩家试玩记录模板

**这是空白模板，不是真实试玩记录。** 每位参与者复制一份，匿名标为 P01、P02、P03。无需姓名、联系方式或账号信息。

## 基本情况

- 玩家代号：待填写
- 日期与游戏版本：待填写
- 浏览器、系统、屏幕尺寸、鼠标/触控板：待填写
- 是否第一次接触本作：待填写
- 平时是否玩解谜游戏：待填写
- 开始前是否清楚这是木作解谜游戏：待填写
- 使用在线版还是离线版：待填写
- 存档条件：新浏览器上下文／玩家主动选择新旅程／其他（注明）

请勿为测试删除玩家已有存档。旁观者不要提前讲解正确顺序；如不得不帮忙，记录具体帮助。

## 时间与操作

- 开始时间、结束时间、主动休息时长：待填写
- 首次完成拆解的时刻：待填写
- 最长不知道下一步做什么的位置：待填写
- 误把旋转当拖动／拖动当旋转：次数与位置待填写
- 受阻后是否尝试撤销、重置或返回：待填写
- 是否发生刷新、退出再继续：待填写
- 游戏本机记录导出文件：待填写（没有则写“未导出”）

自动记录与旁观记录分开保留。内测导出是状态与操作数据，不自动代表玩家心理或理解程度。

## 结束后简短访谈

1. 你为什么会去旧木料库？拿回来的东西准备做什么？
2. 哪一处让你不知道该点哪里或该怎么拖？
3. 哪段对白想跳过？有没有记住周伯说的某句话？
4. 修好长凳后，有没有觉得前面学的东西派上了用场？
5. 哪个画面、声音或动作让你觉得不协调？
6. 如果只改一件事，你希望改什么？

记录原话，不把旁观者的解释改写成玩家结论。

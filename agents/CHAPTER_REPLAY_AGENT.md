# 《榫间》菜单、练习与选章 Agent

## 目标

将主菜单收成继续旅程、开始新旅程、榫卯练习、旅行笔记、设置、作品说明。玩家走完七章并读到结局后，主菜单增加独立的「选择章节」。原独立试玩、重看开场和章节回顾从玩家菜单撤下。

## 三个入口

- **榫卯练习**　按物件选练习，每件可进拆解或拼装。复用现有三维木件、碰撞、提示和撤销。只能通过练习进度继续练习，退出回到选物或主菜单。
- **旅行笔记**　从标题和剧情内查看实际记下的线索、非遗传习资料、作品记录、获奖证书与合影。这里负责翻阅进度。参观过工坊的玩家也可以从笔记回访博物馆。
- **选择章节**　正式旅程以合法参赛历史抵达完整结局后解锁。七个入口分别从下山、初到小屋、清晨取料、返校、选作品、抵达赛场及等待公布进入。从每个入口都可继续往后玩。

作品说明将接头与组合家具的介绍改为「接头和组合家具的灵感来自日常生活中观察的榫卯结构。」

## 跳章和存档

- 进入章节只补齐该处以前的剧情条件与合法木件历史。当章的操作仍照常完成。正式奖项由主存档的流程证明归档。
- 跳过的分歧和选章重玩时的剧情路线用第一项，例如用途问题的第一项和换鞋小凳。可选观察、对白、提示与返退由玩家操作。
- 选章重玩使用独立的会话状态，刷新可以继续该章。主菜单提供结束本次选章试玩的动作，回到原旅程。正式旅程与自由练习各有独立存档。
- 保留一次正式通关获得的本机解锁。旧档已有完整结局时可直接选章，第一幕结束和未完成比赛的档仍按原流程继续。
- 在桌面《榫间》的制作备查区提供「从指定章节试玩」快捷方式。该入口直接开启选章权限，供委托方核查完整游戏。常规 Windows 游戏入口仍按正式结局解锁。

## 实施和核对

1. 清理主菜单和结局菜单，接入旅行笔记及按物件的练习入口。
2. 为七个章首建立与主线条件兼容的起点，接通首次通关解锁、跳章的默认路径与返回。
3. 检查七章均能继续，普通新档、已有完整结局的旧档和制作快捷方式各按预期工作。重点核对选章页面刷新、退出、练习拆装，以及过程没有改写原旅程。
4. 打包并验证桌面 Windows 版，更新桌面《榫间》游戏包和简明说明，把制作入口留在备查区。

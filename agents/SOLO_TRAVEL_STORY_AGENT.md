# 《榫间》独行版剧情 Agent

## 故事目标

陈屿是一名周末独自徒步的大学生。他因雨借宿，在周伯的小屋第一次看懂一个接头。修好雨棚长凳后，他看见一位村民坐下换湿鞋，认识到修好一件旧东西能给人带来什么。回校后，他继续学木作，带着一件方便拆修的家具参赛，领奖后把拆装顺序带回传习屋。

## 节点与交接

| 节点 | 情节和玩家行动 |
| --- | --- |
| `opening`、`villageArrival`、`stay` | 陈屿沿石阶下山。雨水打湿路线图，他进村找地方歇脚，可先去雨棚，也可直接敲门。经周伯邀请进屋、放包和主动询问后借宿。 |
| 长凳检查和试坐 | 周伯检查接缝，确认可以使用。村民进雨棚换掉湿鞋，陈屿亲眼看到修好的长凳重新用起来，随后自己坐下。 |
| `continuationMeetup`、`continuationDeparture` | 修凳后回到雨棚，可直接点击柱上的海报，再取折页或展开细看。离村时向周伯道谢并留下联系方式。 |
| `continuationPurpose` | 在工坊翻出雨棚手记，玩家选择先研究落座、搬动或将来更换座面。用途问题由观察和动手检验回答。 |
| `continuationFinalJudge`、`continuationFinalAfter` | 凳子的动机来自雨棚，床边小几和书架仍来自陈屿自己的生活。比赛结束后，林岚作为同行提出试用，并与陈屿交换做法。 |
| `continuationFinalResult`、`continuationFinalZhou` | 工作人员念名，陈屿领奖、合影并向周伯报喜。最后写下准备带回传习屋的图。 |

## 实施原则

- 描述当时发生的事。村民换鞋发生在长凳经检查后。周伯留在村里，省城通过消息出现。陈屿沿用已有立绘。
- 同步更新对白、热点、目标、笔记、海报、画面和活动名称。历史素材留作档案；运行中的主线场景应与独行剧情一致。
- 沿用节点 ID、任务证明、作品次序和名次。旧存档遇到改写对白时只回到该段开头，未触发的新剧情无需补播。
- 验证两条借宿路线、先前存档、选章试玩与三件作品的展示。真实鼠标走完关键流程后再生成桌面交付。

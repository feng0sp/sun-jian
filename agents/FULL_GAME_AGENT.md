# 《榫间》初版全流程制作 Agent

## 职责和优先级

依据用户已确认的完整初版方案，将遇雨借宿、主动学习、修凳、返校备赛、省城参赛、第三名和继续学习落实为可从头玩到尾的游戏。完整可玩优先，再集中精修。此文档是接手规范，本身不是后台进程。

先读项目 AGENTS.md、docs/STORY_BIBLE.md、agents/STORY_AGENT.md 与最新实际发布记录。代码、合法历史及测试证据优先于过时的进度描述。保留当前未提交修改，不使用旧压缩包覆盖源码。

主角“我”是独自徒步旅行的男大学生陈屿。现代山村、硬朗动漫画风、二维点击探索、独立三维特写、桌面游客访问。所有人物及省级木作交流赛新人组均为虚构。准备约十周，第三名固定，提示和速度不改名次。

## 已批准的新选择

0.15.2 的人物、旅行动机和参赛衔接以 [独行版剧情 Agent](SOLO_TRAVEL_STORY_AGENT.md) 为准。

0.15.1 的主菜单、旅行笔记、练习库与通关选章以 [菜单、练习与选章 Agent](CHAPTER_REPLAY_AGENT.md) 为准。

参赛作品三选一：换鞋小凳、床边小几、桌上书架。每种有独立模型、用途、说明、过程记录和赛后展示；排名一致。只操作一块宽主板和两枚侧向木销，框架由工坊协助预装。选定后可以在备赛确认返回修改；正式出发后保留选择，不让旧历史套到新模型。

## 全流程与切片

- S01—S04：保留开场、借宿、四学习、三必经五自选、三件长凳、告别、雨棚活动折页、返校工坊、主动报名、林岚及维修样机。
- S05：选择作品，装配，观察主板/搬动/取销位置，填写真实协助范围。第五至八周用有变化的三份记录承接，不逐周强制重复。
- S06：保护包装、赴省城登记、现场装配、取销退出主板、复装、说明记录、观展。周伯留在溪桥村，备赛照片与赛后报喜使用消息；无计时和临时资格门槛。
- S07：公布姓名与作品、前三名上台、证书和3000元奖金、合影、林岚试用、周伯远程报喜、最后手记。完成页留在作品现场，提供作品、手记、回顾和菜单。
- S08：新旧完整路线、实际指针、迁移、三尺寸、资源失败、无 WebGL、声音及离线验证，然后更新原公开站。

## 每个节点卡必须包含

稳定 ID、时间/场景/在场者、入场条件、当前目标、原创短对白与条件变体、实际动作、单次提交结果、下一节点及返回点、刷新恢复、图片状态、验收路径。主线对白通常 2—4 回合；可选追问不挡通关。

## 接口和保存约束

完整初版里程碑 0.14.0，当前参赛与领奖修整 0.14.3，主键 sun-jian-campaign-v1、数据版2，剧情修订12，continuation 修订5；写迁移前保存原文备份。旧工坊完成档进入作品准备，旧第一幕完成不等于获奖。

作品结构 ID：entry-shoe-stool、entry-bedside-table、entry-desk-shelf。任务 ID：entry-stool-assemble、contest-assemble、contest-service-out、contest-service-back；任务身份不因选书架而改变，level 身份随选件验证。四任务共享选定模型，分别保存证明；重练不覆盖正式历史。阶段由合法历史推导，单个布尔值不能授奖。预览不落盘，失焦/取消/切换回滚。

## 表现与交付

全景仅使用绘制状态，不贴微型三维木块。模型先定稿、再生成场景图。固定人物/背包/作品透视光色一致；男性和女性头像按实际说话人切换。五类轻快音景默认关闭，暂停可续乐句，后台暂停；不扩展整篇配音。

每切片记录已实现/已验证/问题/下一步/是否发布。交付完整节点、可玩的全流程、同源离线包、后半段实机演示、图片与对白检查、已知问题和回退版本。至少覆盖不做自选、两销换序、最高提示、正式比赛退出刷新、重练不颁奖、旧存档和图片失败。首次玩家意见待真人收集，不虚构，也不阻挡已验证的初版试玩。
